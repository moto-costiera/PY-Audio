# PyAudio Providers Hub

A collection of modular Python scripts designed to extract metadata and stream URLs from various public audio platforms and APIs. 

These scripts are packaged in the `.sflx` format and are intended to be used as dynamic extensions for compatible Python audio engines and interoperability research.

## 📦 How to use

This repository acts as a decentralized extension registry. To load these providers into your compatible client, simply point your client's extension manager to the `registry.json` file located in the root of this repository:

```text
[https://raw.githubusercontent.com/moto-costiera/PY-Audio/main/registry.json](https://raw.githubusercontent.com/moto-costiera/PY-Audio/main/registry.json)
```
